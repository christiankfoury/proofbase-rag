# Acceptable Use Policy

## Approved Use

Northstar systems must be used for company business, approved learning, customer support, and authorized operational work. Employees may use company devices for limited personal use if it does not interfere with work, create security risk, or violate policy.

## Approved Software

Employees should use company-approved software for messaging, file storage, source control, project tracking, and customer collaboration. Unapproved software that stores company data must not be used without IT review.

## Account Sharing

Employees must not share passwords, MFA codes, access tokens, or accounts. Each employee is responsible for activity performed under their account.

## AI Tool Usage

Employees may use approved AI tools for drafting, summarization, and analysis when the data classification allows it. Confidential or restricted data must not be pasted into unapproved AI tools.

Generated AI output must be reviewed before being sent to customers, used for policy interpretation, or relied on for security decisions.

## Prohibited Behavior

Employees must not attempt to bypass security controls, scan systems without approval, copy customer data to personal storage, or use company systems for illegal, harassing, or discriminatory activity.

## Related Policies

Device requirements are defined in the Device and BYOD Security Policy. Data handling requirements are defined in the Data Classification and Handling Policy.
