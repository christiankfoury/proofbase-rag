## Outcome and scope

Make the existing assistant answer supported questions reliably while retaining
permission filtering, grounded claims, faithful citations and safe abstention.
Fix one demonstrated root cause at a time, using a failing local reproduction,
the smallest complete change, positive/negative controls and a reviewed commit.

Affected surface: App chat and its response behavior; backend retrieval,
orchestration, generation and validation only where evidence identifies a defect.
No new database model or UI redesign is planned. Dev/Admin changes are needed
only if an existing displayed claim becomes inaccurate. No cloud work, model
switch, evaluator rewrite, automatic retry expansion or broad refactor is planned.

The first implementation milestone is **verified local behavior improvements**,
not a replacement overall score. Mocked checks establish code behavior under
specified inputs; they cannot establish live model quality or generalization.
