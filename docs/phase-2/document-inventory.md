## Required Content by Document

- **HR-001 Employee Handbook:** company values, working hours, code of conduct, onboarding basics, employee support channels. Do not include detailed compensation bands.
- **HR-002 PTO and Leave Policy:** vacation entitlement, sick leave, company holidays, parental leave summary, approval workflow. Include edge cases like carryover limits and notice period.
- **HR-003 Remote and Hybrid Work Policy:** eligible work locations, remote approval, cross-border work limits, office expectations, manager approval. Include ambiguity around temporary international work.
- **HR-004 Benefits Overview:** health plan summary, wellness stipend, learning budget, retirement matching summary. Do not include provider contract details.
- **HR-ADMIN-001 HR Policy Operations Guide:** policy ownership, internal HR escalation paths, sensitive case handling, employee relations workflow. Restricted to HR Admin.
- **IT-001 Acceptable Use Policy:** approved software, prohibited behavior, account sharing, company device use, AI tool usage boundaries.
- **IT-002 Device and BYOD Security Policy:** device encryption, personal device rules, lost/stolen device reporting, mobile device management, local storage restrictions.
- **IT-003 Data Classification and Handling Policy:** classification levels, examples, storage rules, sharing rules, retention basics.
- **IT-ADMIN-001 Privileged Access and Incident Response Guide:** access review cadence, privileged account handling, incident triage workflow, restricted admin procedures. Do not include fake passwords, secrets, or exploit details.
- **SALES-001 Sales Playbook:** ideal customer profile, discovery questions, sales process stages, handoff rules, approved talk tracks.
- **SALES-002 Product Positioning and FAQ:** core value props, industry use cases, implementation timeline, integrations, approved product limitations.
- **SALES-003 Competitive Battlecard:** competitor comparison, approved objection handling, prohibited claims, positioning boundaries.
- **MGR-001 Manager Handbook:** manager responsibilities, 1:1 expectations, escalation paths, team planning, conflict handling.
- **MGR-002 Performance Review and Promotion Guide:** review cycle, documentation expectations, promotion criteria, calibration process, performance improvement process.
