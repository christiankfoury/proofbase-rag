# Phase 64 — evaluator and measurement protocol

The goal is a current-runtime measurement with inspectable evidence, rather than substituting a lower number for the old 100% claim. The application and legacy benchmark remain unchanged.

Implemented a separate semantic fact/claim rubric plus deterministic exact-quote, authorized-chunk and schema checks. A complete response must include every material expected fact and support every factual assertion with its exact cited passage. Uncertainty fails closed. Speech acts such as refusals need no citations, but factual disclosures inside them do. These are model judgments, not proof of truth or human validation.

Calibration artifacts preserve all attempts. Version 1 agreed on 17/21 fixtures: it mistakenly accepted an unrelated cited passage and misclassified three non-answers. Version 2 agreed on 18/21 after limiting evidence to exact citations, but still misclassified non-answers. Version 3 explicitly distinguishes factual assertions and speech acts and agreed on 24/24, including three additional refusal-with-disclosure negatives. Fixtures and labels were authored by the implementation agent and tuned during development. This agreement is a readiness check, not held-out evaluator accuracy. Existing benchmark labels were authored by the project owner with AI assistance.

The runner uses the actual `/query` endpoint in an isolated clone of the local database. A visible development smoke returned HTTP 200, an answer and five retrieved chunks. It used the current active prompt and real provider calls. External telemetry delivery failed during that smoke; measurement disables telemetry delivery and records that harness difference. Application calls are capped at 2048 output tokens, SDK retries disabled, logs/uploads/quarantine isolated; all differences are disclosed in the freeze environment. This is the current application under an explicit evaluation configuration, not proof of deployed performance.

The $0.75 shared ledger reserves costs before application and grader calls. Unknown outcomes block subsequent calls. Pricing uses uncached input rates conservatively: [GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini) and [text-embedding-3-small](https://developers.openai.com/api/docs/models/text-embedding-3-small), checked 2026-09-14. Provider variability remains possible even at temperature zero. Raw responses precede grading; started runs are never replayed. Incomplete runs publish no full-suite rate. Per-case human review remains pending until an actual named person completes it.

Verification: 12 focused tests and 7 existing evidence tests pass; legacy benchmark validation and public-evidence reconstruction pass. Calibration and smoke cost are retained in the shared API ledger. No old holdout was executed or edited. Fresh authoring is prohibited until evaluator, runner, corpus, settings and indexed database are frozen after commit/review.
